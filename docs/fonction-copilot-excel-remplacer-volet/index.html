La fonction COPILOT() d’Excel s’arrête aujourd’hui : comment garder l’IA dans tes tableaux

Si tu utilisais la fonction =COPILOT() directement dans tes cellules, mauvaise nouvelle : Microsoft la retire à partir du 14 septembre 2026. Bonne nouvelle : l’IA ne quitte pas Excel, elle change juste de porte d’entrée — et elle est devenue bien plus puissante. Voici comment garder Copilot dans Excel sans rien perdre, et même en faire plus qu’avant.

Ce qui change (et pourquoi ne pas paniquer)

La fonction =COPILOT(), qui permettait d’appeler l’IA au cœur d’une formule, est restée en préversion depuis août 2025. Microsoft a décidé de ne pas la pérenniser : à partir du 14 septembre 2026, elle cesse de fonctionner. L’éditeur redirige les utilisateurs vers le volet latéral Copilot, qui reprend l’essentiel des usages (résumer, classer, générer, aller chercher une information) et en ajoute de nouveaux.

Traduction concrète : tu ne perds pas l’IA, tu passes d’une petite fonction fragile à un vrai assistant intégré. La méthode change, la valeur augmente.

Comment retrouver la même chose via le volet Copilot

  1. Ouvre ton classeur, onglet Accueil → clique sur le bouton Copilot (à droite du ruban). Le volet s’ouvre sur le côté.
  2. Sélectionne la plage de données concernée avant de poser ta demande : Copilot travaille mieux avec un contexte clair.
  3. Formule une consigne précise, par exemple : « Classe ces avis clients en 3 catégories (positif / neutre / négatif) dans une nouvelle colonne. »
  4. Vérifie la proposition, puis valide pour l’insérer dans la feuille. Tu gardes toujours la main sur le résultat.

Le réflexe à garder : une bonne demande contient l’action + la plage + le format de sortie attendu. C’est 80 % de la réussite.

Le nouveau super-pouvoir : Python dans Excel via Copilot

Depuis fin août 2026, « Edit with Copilot » peut exécuter du Python directement dans Excel : statistiques avancées, simulations, visualisations, nettoyage de données… le tout sans quitter ton classeur. Tu n’as pas besoin de coder toi-même : tu décris le résultat, Copilot génère et exécute le code, et la sortie atterrit dans la feuille.

Exemple de demande à taper dans le volet :

À partir de la plage A1:D500 (ventes mensuelles),
calcule le chiffre d'affaires par région, identifie les 3 régions
en baisse sur les 6 derniers mois, et génère un graphique clair.
Utilise Python si nécessaire.

Ce qui demandait un tableau croisé dynamique + plusieurs formules se fait désormais en une phrase. Ton rôle : cadrer la demande et vérifier le résultat.

La compétence que l’IA ne remplacera pas : comprendre tes données

Copilot va vite, mais il ne sait pas si ton fichier est propre. Maîtriser les fondamentaux reste décisif. Un exemple qui sauve des heures : remplace tes vieux RECHERCHEV par RECHERCHEX (XLOOKUP), plus souple et sans colonne de référence à compter :

=RECHERCHEX(A2 ; Clients[Email] ; Clients[Nom] ; "Introuvable")

L’IA t’aide à aller plus vite ; les bases t’évitent de foncer dans le mur plus vite. Les deux ensemble, c’est ça la vraie montée en compétences sur Excel et Microsoft 365.

Sur le sujet IA, lis aussi : la compétence IA à ne pas rater cette rentrée.
